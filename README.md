# MERN Starter

A standard full-stack starter with:

- React + Vite frontend
- Express + TypeScript backend
- Root workspace scripts for running both apps together

## Quick start

1. Install dependencies:
   npm install

2. Start both apps:
   npm run dev

3. Open the frontend at http://localhost:5173

4. API health check: http://localhost:5000/api/health

## Scripts

- `npm run dev` — start the frontend and backend together
- `npm run build` — build both applications
- `npm run start` — start the backend in production mode

## Environment

Create a backend `.env` file based on `.env.example` if you need custom configuration.
